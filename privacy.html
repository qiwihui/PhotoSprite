隐私政策

相册精灵 · 生效日期：2026 年 10 月 11 日

一句话总结：照片的分析都在你的 iPhone 上完成，我们没有服务器，不收集、不出售任何数据。只有当你主动使用「助手」功能时，你的消息和照片的统计信息会用你自己的 API key 或账号直接发送给你选择的 AI 服务商。

1. 在设备上处理的数据

为了给出整理建议，App 会在你的 iPhone 上读取照片库，并用 Apple 的 Vision 框架分析：

  • 照片的日期、位置、尺寸、是否收藏等元数据；
  • 画质评分、内容标签（如「海滩」「猫」）、人脸数量和拍摄质量、镜头脏污程度；
  • 截图和文档类照片中的文字、二维码和条形码内容。

分析结果只保存在 App 的本地存储中，不会上传。照片位置会通过 Apple 地图服务转换成城市名（只发送坐标，不发送照片）。

2. 语音输入

在「助手」中使用语音时，App 会使用麦克风，并通过 iOS 自带的语音识别（Speech 框架的 SFSpeechRecognizer，与键盘听写相同）把语音转成文字。设备支持时识别在 iPhone 上完成；不支持时，iOS 会把音频发送给 Apple 识别，处理遵循 Apple 的隐私政策。本 App 自己不会保存录音，也不会把录音发给 Apple 以外的任何人。转出的文字和你打字输入的消息一样处理（见下一节）。朗读回复使用系统自带的语音合成，同样在设备上完成。

3. 使用「助手」时发送的数据

「助手」是可选功能，首次使用前会单独征求你的同意。使用时，以下内容会发送给你在设置中选择的 AI 服务商（如 Anthropic、OpenAI、Google、OpenRouter、DeepSeek）：

  • 你输入或用语音说出的消息（只发送识别后的文字）；
  • 照片的统计信息，例如数量、日期、城市名、相册名；
  • 助手需要读取文字时，在设备上识别出的文字；
  • 助手需要确认画面时，少量缩小后的照片（最长边 512 像素）。

这些请求使用你自己的 API key 或账号，从你的设备直接发送给服务商，不经过我们的服务器。服务商如何处理这些数据，请参阅你所选服务商的隐私政策。

如果你选择 OpenRouter 的免费模型（名称带「免费」标记），请注意：这些模型由不同的服务商提供，部分服务商可能会保存你的消息或用于训练模型，具体取决于你在 OpenRouter 网站上的隐私设置。请不要通过免费模型发送敏感内容。

如果你用 ChatGPT、GitHub Copilot、SuperGrok / X Premium、Kimi Code 或 Meta 的订阅账号登录，登录同样在 Apple 的安全网页窗口里完成，服务商发给本 App 的登录凭证保存在本机钥匙串里，只用来向该服务商发送助手的请求；本 App 看不到你的密码，你可以随时在 App 里退出登录。

如果你用 OpenRouter 账号登录，登录在 Apple 的安全网页窗口里完成，OpenRouter 会为本 App 生成一个 API key，保存在本机钥匙串里；本 App 看不到你的 OpenRouter 密码。你可以随时在 App 里退出登录，或在 OpenRouter 网站上撤销这个 key。

4. API key

你填写的 API key 保存在 iOS 钥匙串中，只用于向对应服务商发送请求。你可以随时在「设置」中移除。

5. 我们不做的事

  • 不运营任何服务器，不收集任何个人数据；
  • 不使用广告、统计分析或追踪 SDK；
  • 不出售、不共享你的数据；
  • 不会在未经你确认的情况下修改或删除照片：所有删除和建相册操作都需要你在审核页确认，删除时 iOS 还会再次确认。

6. 删除数据

在「设置 › 重新分析照片库」可以清除本地分析结果；卸载 App 会删除它在设备上保存的全部数据。已发送给 AI 服务商的数据，请联系对应服务商处理。

7. 儿童

本 App 不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

8. 变更

如果本政策有变更，我们会更新本页面并修改生效日期。
