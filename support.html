快速上手

  1. 首页：打开就有整理建议（相似照片、二维码截图、旧截图、拍糊的照片、大视频、每月精选、旅行相册），全部在 iPhone 上分析，免费。
  2. 审核：点一条建议查看照片，取消不想处理的，再删除或存入相册。
  3. 助手：点右下角的圆形按钮。在设置里登录 OpenRouter 或填入自己的 API key 后，用一句话描述需求，例如「今年去过哪些地方？每个地方挑 10 张最好的建相册」。

App 里的「使用指南」（左下角问号）有更多示例，点一下就能试。

常见问题

怎么用语音？

在「助手」里点麦克风说话，停顿 2 秒自动发送，回复会读给你听。使用 iOS 自带的语音识别（和键盘听写相同），不需要下载模型：iPhone 支持时在设备上识别，否则由 Apple 的服务器识别。本 App 不会保存或上传录音。第一次使用会请求麦克风和语音识别权限。可以在「设置 › 语音」里调整；打开「连续对话」后，回复读完会自动接着听，8 秒没说话就结束。

删错了怎么办？

删除的照片在「照片」App 的「相簿 › 最近删除」里保留 30 天，可以恢复。

照片会上传吗？

不会。分析都在 iPhone 上完成。只有使用助手时，消息和照片统计信息会发给你选择的 AI 服务商，详见隐私政策。

为什么第一次要分析很久？

需要逐张分析画质、人脸、内容和文字。几千张照片可能要十几分钟，分析期间可以正常使用；接上电源时 App 会在后台继续。

只能访问部分照片？

如果授权时选了「限制访问」，建议只覆盖你允许的照片。可以在首页顶部点「选择更多照片」，或在「设置 › 隐私与安全性 › 照片」里改为完全访问。

助手要花多少钱？去哪里拿 API key？

费用由 AI 服务商按用量直接收取，默认使用便宜的小模型，一次整理通常只要几分钱。API key 可以在 platform.claude.com（Anthropic）、platform.openai.com/api-keys（OpenAI）、aistudio.google.com/apikey（Google）、openrouter.ai/keys、platform.deepseek.com/api_keys 创建。

能免费用助手吗？

可以用 OpenRouter 的官方免费模型：在设置里选 OpenRouter，点「使用 OpenRouter 账号登录」（注册免费；也可以粘贴自己创建的 key），再点「改用免费模型」。限制为每分钟 20 次、每天 50 次（累计充值满 $10 后每天 1000 次）；部分免费模型的服务商可能保存或用你的消息训练模型，取决于你在 OpenRouter 的隐私设置。

能用订阅账号登录吗？

可以用 ChatGPT、GitHub Copilot、SuperGrok / X Premium、Kimi Code、Meta 的账号直接登录，请求计入你的订阅额度；也可以用 OpenRouter 账号登录。Claude Pro/Max 不支持：Anthropic 只允许在 Claude 自己的 App 和 Claude Code 里使用订阅登录，想用 Claude 请填 Anthropic API key，或通过 OpenRouter 使用。

某张照片一直被建议删除？

在审核页取消选择后再执行，以后同类建议就不会再推荐它。
